# Guide de Contribution pour Echo Assistant

Merci de l'intérêt que vous portez à Echo Assistant ! Nous apprécions les contributions de la communauté.

## Comment Contribuer ?

Il y a plusieurs façons de contribuer :

*   **Signaler des Bugs :** Si vous trouvez un bug, veuillez ouvrir une [Issue](https://github.com/[votre-username]/EchoAssistant/issues) en décrivant le problème le plus précisément possible (étapes pour reproduire, version utilisée, système d'exploitation, message d'erreur complet, captures d'écran si pertinent).
*   **Suggérer des Fonctionnalités :** Vous avez une idée pour améliorer Echo Assistant ? Ouvrez une [Issue](https://github.com/[votre-username]/EchoAssistant/issues) en décrivant votre idée et pourquoi elle serait utile.
*   **Proposer des Modifications (Pull Requests) :** Si vous souhaitez corriger un bug ou implémenter une fonctionnalité, suivez ces étapes :
    1.  **Forkez** le dépôt sur votre propre compte GitHub.
    2.  **Clonez** votre fork localement (`git clone https://github.com/VOTRE-USERNAME/EchoAssistant.git`).
    3.  **Créez une branche** pour votre modification (`git checkout -b feature/nouvelle-fonction` ou `fix/description-bug`).
    4.  **Effectuez vos modifications** dans le code.
    5.  **Testez** vos changements pour vous assurer qu'ils fonctionnent et ne cassent rien d'autre.
    6.  **Commitez** vos changements avec un message clair (`git commit -m "Ajout fonctionnalité X"` ou `git commit -m "Correction bug Y"`).
    7.  **Poussez** votre branche vers votre fork (`git push origin feature/nouvelle-fonction`).
    8.  **Ouvrez une Pull Request (PR)** depuis votre branche vers la branche `main` (ou `develop` si elle existe) du dépôt original. Décrivez clairement les changements effectués dans la PR.

## Style de Code

Veuillez essayer de suivre les conventions de style [PEP 8](https://www.python.org/dev/peps/pep-0008/) pour le code Python. Utilisez des noms de variables et de fonctions clairs et ajoutez des commentaires si nécessaire.

## Code de Conduite

En contribuant à ce projet, vous acceptez de respecter le [Code de Conduite](CODE_OF_CONDUCT.md).

Merci encore pour votre contribution !
